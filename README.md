# EXE Smart Cities — site

Site institucional da EXE Smart Cities, refeito do zero em HTML, CSS e JS puros (sem build).

## Rodar localmente

```bash
python3 -m http.server 5510
```

Abra http://localhost:5510

## Estrutura

```
index.html          página única
css/style.css       estilos (tokens de cor e tipografia no :root)
js/main.js          header, menu mobile, galeria do residencial
assets/img/         imagens em uso
assets/originais/   arquivos do site antigo que não estão em uso
```
